# 2026-11-10 数学页三个小游戏交互改造（FR-18 v1.5）

## 图案与数字连线：点选 → 手动拖拽连线
- pages/link：按住点阵/数字卡拉出跟随手指的虚线（`.ln-live` + 末端圆点），松手落在对岸卡片即判分。
- 关键实现：`catchtouchmove` 防拖动时页面滚动；距离节流（<4px 不重绘）；`utils/link.js` 新增纯函数 `hitRect`（命中测试，外扩 16px 容错）和 `lineGeom`（两点→线参数）；`cacheRects()` 一次性缓存棋盘+两列卡片 rect，拖动中不查布局；支持双向拖（数字→点阵）；拖空白取消；轻点退回"点两下"老玩法（`pick/judge` 保留为兜底）；卡片两端 `.ln-handle/.rc-handle` 连接点提示。

## 思维游戏-迷宫：小人和旗子不显示的根因修复
- **根因**：WXML 写了 `{{cell.cls.indexOf('me') > -1}}`——**WXML 表达式不支持方法调用**，恒为假 → 小人和旗子都不渲染，方向键其实在走但玩家看不见（"点击没反应"的真相）。
- 修复：`renderMaze` 输出 `isMe/isGoal/isWall` 布尔，WXML 只判布尔；小人 🧒（黄底格+脉冲）、旗子 🚩（绿格+摆动）用 emoji 保证可见；`faceSize` 随 cellRpx 缩放；方向键盘改十字布局（图标+汉字）；撞墙时盘面 `.bump` 抖动。

## 思维游戏-方块滑块：点按 → 按住拖动
- 3×3 改绝对定位（格距 186rpx，容器 548rpx），`wx:key="n"` 按数字复用 DOM，`left/top` transition 即滑动动画。
- 交互：按住抬起（scale 1.06），拖动锁定主方向、上限一格（`pitchPx()` rpx→px 换算），松手方向正对空位 → 先 150ms transform 动画滑到空位再落数据（不跳），方向不对回弹；轻点相邻块仍自动滑一格。
- `utils/mind.js` 新增纯函数：`snapDir`（主方向）、`stepIndex`（越界 -1）、`dirOffset`、`dirToBlank`。
