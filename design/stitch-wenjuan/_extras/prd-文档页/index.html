进入朗读器：逐句「听范读 → 自己读（录音）」 → 每完成一句：即时鼓励反馈，进度本地保存 → 全部句子完成（或手动结束） → 完成激励页：完成度星 + 朗读小结 + 奖状 → 判定勋章解锁 → 解锁动画 → 分享（海报 / 小程序卡片） ``` ### 3.2 幼儿园模式分支 与主流程一致，差异点： - 朗读器中无星级反馈，只有鼓励动画 + 语音夸奖（每句随机夸奖语） - 完成激励页固定满星，庆祝动画更长 - 奖状文案使用「小小朗读者」等纯鼓励措辞，无「优秀/良好」分级 ### 3.3 断点续读流程 朗读中途退出（返回/切后台/杀进程）→ 进度与已录音频写入本地缓存 → 首页出现「继续学习」卡片 → 点击恢复到中断的句子位置。 ### 3.4 生词流程 朗读前识别结果中，超出用户年级常用字表（低年级模式）或长难词（高年级模式）自动标记为生词 → 完成朗读后提示「发现 X 个生词已收入生词本」→ 生词本可筛选、标记掌握度 → 「复习」进入简化朗读器。 --- ## 4. 功能模块详细说明 > 编号规则：FR-模块号-序号。【P0】v1 必须；【P1】v1 尽量；【P2】后续版本。 ### M1 账号与登录 | 编号 | 功能 | 说明与规则 | 优先级 | |------|------|-----------|--------| | FR-1-1 |
