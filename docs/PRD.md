## 1. 产品概述

### 1.1 产品定位
书声岛是一款**拍照朗读练习小程序**：孩子把课本、绘本、练习册拍下来，AI 识别文字并自动分句，先逐句播放范读让孩子「听熟」（磨耳朵），再由孩子自主选择开口跟读，完成后获得奖状与勋章，形成「拍照 → 听读 → 朗读 → 完成激励 → 分享」的学习闭环。

**一句话描述**：拍一拍课本，跟着读，攒勋章。

### 1.2 v1 范围（已确认决策）

| 决策项 | 结论 |
|--------|------|
| 语音评测 | ❌ v1 不接入语音评测 SDK，不做 AI 纠音评分；星级为完成度激励 |
| 账号体系 | ✅ 微信静默登录 + 本地记录；家长报告页引导绑定手机号 |
| 幼儿园模式 | ✅ 提供「跟读不评分、只鼓励」的纯激励分支 |
| 家长端 App | ❌ 不做 App 及数据同步；生词本 v1 仅本地存储 |
| 视觉设计 | 由 Stitch 原型设计承接，本文档只定义功能与交互逻辑 |

### 1.3 用户角色与权限

| 角色 | 说明 | 可用功能 |
|------|------|---------|
| 孩子用户（主） | 打开小程序即用，无需注册 | 拍照、朗读、激励、生词本、勋章、个人中心基础设置 |
| 家长 | 与孩子共用设备，通过门禁进入 | 学习报告、绑定手机号、下载引导、安全设置 |
| 游客（H5） | 通过分享链接打开 H5 落地页 | 播放试听、点赞、跳转小程序 |

## 3. 核心业务流程

### 3.1 主流程：拍照 → 朗读 → 激励

```
首页点击「拍照开读」
  → 相机拍摄 / 相册导入（1–9 张）
  → 图片整理确认（可排序、删减）
  → OCR 逐张识别（失败可重试/跳过）
  → 生成分句朗读任务（一组课文）
  → 进入朗读器：逐句「听范读 → 自己读（录音）」
  → 每完成一句：即时鼓励反馈，进度本地保存
  → 全部句子完成（或手动结束）
  → 完成激励页：完成度星 + 朗读小结 + 奖状
  → 判定勋章解锁 → 解锁动画
  → 分享（海报 / 小程序卡片）
```

### 3.2 幼儿园模式分支
与主流程一致，差异点：
- 朗读器中无星级反馈，只有鼓励动画 + 语音夸奖（每句随机夸奖语）
- 完成激励页固定满星，庆祝动画更长
- 奖状文案使用「小小朗读者」等纯鼓励措辞，无「优秀/良好」分级

### 3.3 断点续读流程
朗读中途退出（返回/切后台/杀进程）→ 进度与已录音频写入本地缓存 → 首页出现「继续学习」卡片 → 点击恢复到中断的句子位置。

### 3.4 生词流程
朗读前识别结果中，超出用户年级常用字表（低年级模式）或长难词（高年级模式）自动标记为生词 → 完成朗读后提示「发现 X 个生词已收入生词本」→ 生词本可筛选、标记掌握度 → 「复习」进入简化朗读器。

## 4. 功能模块详细说明

> 编号规则：FR-模块号-序号。【P0】v1 必须；【P1】v1 尽量；【P2】后续版本。

### M1 账号与登录

| 编号 | 功能 | 说明与规则 | 优先级 |
|------|------|-----------|--------|
| FR-1-1 | 微信静默登录 | 首次启动调用 `wx.login` 换取 openid，无需用户授权弹窗；openid 仅作为本地数据索引 | P0 |
| FR-1-2 | 本地用户档案 | 默认昵称「小朗读者」+ 随机卡通头像；首访引导页可修改昵称、选择年级（决定默认年龄模式与生词字表难度） | P0 |
| FR-1-3 | 手机号绑定 | 仅在家长报告页触发，需家长门禁通过；绑定后用于后续多设备同步预留（v1 不同步数据） | P1 |
| FR-1-4 | 数据本地化 | 全部学习数据（课文组、录音、生词、勋章）存储于本地 Storage；提供「清除缓存」入口并二次确认 | P0 |

|------|------|-----------|--------|

| 编号 | 功能 | 说明与规则 | 优先级 |

### M4 OCR 识别与文本处理

| 编号 | 功能 | 说明与规则 | 优先级 |
|------|------|-----------|--------|
| FR-4-1 | 印刷体识别 | 使用微信 OCR 能力（通用印刷体）识别图片文字 | P0 |
| FR-4-2 | 自动分句 | 按中文标点（。！？；…）与换行分句；单句过长（>40 字）按逗号二次切分；过滤页眉页脚噪声（页码、纯数字行、单字符行） | P0 |

| FR-4-4 | 识别失败处理 | 单张识别失败：该图标记失败角标，提供「重试 / 跳过」；跳过不阻塞其余图片 | P0 |
| FR-4-5 | 识别超时 | 单张超 8 秒提示重试；识别结果（文本+分句）本地缓存，避免重复识别 | P0 |
| FR-4-6 | 识别结果可编辑 | 【P1】提供识别结果微调：删除噪声句、合并句子 | P1 |
| FR-4-7 | 英文支持 | 【P2】英文课文分句（按 . ! ?）与范读 | P2 |

## 6. 数据模型（本地存储）

```
User            用户档案
├─ openid, nickname, avatar, grade, ageMode(小学|幼儿园)
├─ phone(可选，加密存), createdAt

BookGroup       一组课文（一次拍照任务）
├─ groupId, createdAt, status(识别中|进行中|已完成)
├─ pages[]: { pageId, imagePath(本地), ocrStatus, rawText }
└─ sentences[]: { sentenceId, pageId, text, pinyin, order, status(未读|已读|跳过) }

Recording       跟读录音（仅本地）
├─ recordingId, sentenceId, filePath, duration, createdAt

Badge           勋章
├─ badgeId, name, conditionExpr, rarity, unlockedAt|null

Award           奖状
├─ awardId, title, starLevel, date, nicknameSnapshot, groupId

Word            生词
├─ wordId, text, pinyin, sourceGroupId, mastery(生疏|一般|已掌握), createdAt

DailyStat       每日统计
├─ date, readSentences, skipSentences, duration, checkedIn(bool)

Streak          连续打卡
├─ current, longest, lastCheckInDate
```

存储要求：录音与图片放临时/本地文件目录并纳入缓存管理；统计与勋章用 Storage 结构化存储；key 命名统一前缀 `wjqd_`。

## 7. 状态与异常处理规范（全局）

### 7.1 空状态
| 场景 | 表现要求 |
|------|---------|
| 无历史课文组 | 首页「继续学习」卡片隐藏，主 CTA 上移 |
| 生词本为空 | 引导语 +「去拍照」CTA |
| 勋章墙全灰 | 展示第一枚「新人勋章」解锁路径预览 |
| 无奖状 | 引导完成第一次朗读 |
| 相册 0 张选中 | 确认按钮禁用 + 文案提示 |

### 7.2 加载状态
| 场景 | 要求 |
|------|------|
| OCR 识别 | 逐张骨架屏 + 轮播文案；单张 >8s 可重试 |
| 完成统计 | ≤2s 出小结，超时降级直接展示奖状 |
| 图片上传 | 缩略图环形进度（仅 OCR 上传场景） |
| TTS 首次加载 | 播放按钮 loading 态，>3s 提示重试 |

### 7.3 异常与错误
| 场景 | 处理 |
|------|------|
| 相机/相册权限被拒 | 页内引导卡 + 去授权直达 |
| 网络断开 | 顶部黄条提示；已识别内容可离线朗读；统计联网补算 |
| 识别失败 | 单张标记失败，可重试/跳过，不阻塞整组 |
| 录音失败（麦克风占用） | toast 提示 + 自动重试入口；不丢进度 |
| 存储空间不足 | 提示清理缓存（录音/图片），勋章奖状数据不受影响 |

## 8. 埋点需求（v1 核心）

漏斗事件：`home_view → camera_enter → photo_confirm → ocr_success → first_sentence_read → group_complete → award_view → badge_unlock → share_click`

关键指标：
- 主漏斗各步转化率
- 单次会话朗读句数、单组完成率
- 打卡留存（次日/7 日）、勋章解锁后的次日回访
- 幼儿园模式与小学模式占比

---

## 9. 非功能需求

1. **性能**：启动 ≤3s；页面切换动画 ≤300ms；单张 OCR 上传图片 ≤1MB；奖状列表 >50 张时虚拟滚动。
2. **弱网/离线**：识别结果与进度本地缓存；核心朗读流程可离线（TTS 不可用时降级自读）。
3. **适配**：以 375px 宽为最小基准适配至 iPad 竖屏；锁定竖屏；底部安全区预留；触控目标 ≥88rpx。
4. **未成年人合规**：不收集非必要个人信息；录音不上传；手机号仅在家长门禁后收集并加密存储；无广告、无内购（v1）。
5. **可用性**：核心按钮配语音引导（可关）；色对比 ≥4.5:1；状态不只靠颜色区分。
