# 书声岛 · 微信小程序（v1.0）

按 Stitch 原型复刻的「拍照朗读」小程序，已接入**真实 OCR + TTS（同声传译插件）**，并补齐**生词本**与**家长中心**。

## 一、功能总览

| 模块 | 页面 | 说明 |
|------|------|------|
| 首页 | `pages/home` | **语文/数学/英语三学科分区**（学科选择持久化）、**快速入口置顶**（拍照伴读/生词复习/听范读/我的奖状，v1.4 移至原「每日伴读小任务」大卡位置，hero 卡与吉祥物已删除）、断点续读、文字描写进度卡、英语音标进度卡、勋章预告；数学/英语其余内容为筹备中；**消息中心**（右上角铃铛：勋章解锁 / 连续打卡里程碑 3·7·14·30·60·100 天 / 留言被回复三类本地通知，未读红点、全部已读、点消息跳转对应页面，`utils/notify.js`，最多保留 50 条）；年龄模式标签点击直达家长中心 |
| 文字描写 | `pages/write` | **分学段中文描写字库**（幼儿园/一年级上/一下/二年级上/二下，共 124 字，含拼音与组词）、田字格描红（楷体底字可开关）、Canvas 手指描写（三档笔粗/撤销/清空）、**「读音」按钮 + 组词点读**（TTS）、写完自动打勾并记录进度；**笔迹回看**：写完的字保存手写笔迹，再次进入自动恢复显示，可「重新描写」（撤销只作用新笔画）；**横屏描写**（`pageOrientation: auto`）：左侧「笔顺教程」逐笔演示（重播/逐笔/暂停 + 进度点），右侧真实描写田字格，左右布局按屏幕 px 动态计算，旋转时笔迹按归一化坐标无缝还原；**宠物学伴**（小鸡/小狐狸/小青蛙 3 皮肤，点宠物换肤并持久化）：平时上下打量，写完一个字跳跃庆祝撒花，换字时飞走带出旧字滑出/新字滑入动效 |
| 英语音标 | `pages/phonetics` | **48 个国际音标**（元音 20：长元音 5/短元音 7/双元音 8；辅音 28：爆破/摩擦/破擦/鼻音/舌侧/半元音，`utils/phonetics.js`，每音标配 audio 单音文件名），9 类分组切换、大符号展示、**「单音」按钮（播这个音本身的单音音频 sounds/ipa/，不再是代表词；支持慢速 0.85x；音频缺失自动退回代表词 TTS 并明示）**、3 个例词（英文 + 中文 + 点读）；**口型舌位图**（`utils/mouthChart.js` 逐音标绘制口腔侧视剖面：唇形/下颌开合/舌头位置/阻塞点/气流方向/鼻腔通道/声带振动，双元音带舌位滑动箭头）+ 发音要点；点「我读会啦」打勾并自动跳下一个，48 格总览按组打勾记录进度。**口型舌位图用旧版 canvas（非同层渲染）绘制**——canvas 2d 在部分真机会卡死整个 WebView，已弃用；页面所有方法带 try/catch 兜底，出错时顶部出现可复制的错误浮层。**发音走英文语种 en_US 合成**（中文通道读英文单词会失败/跑调，`utils/tts.js` 按内容自动判语种），合成 9s 无响应自动超时；语音不可用时卡片里挂一条可点的提示条，点开看「语音自检」结果。口型舌位图不依赖 `ctx.ellipse`（微信 canvas 2d 没有这个 API，会中断整张图），画布初始化失败或绘制异常时自动降级为 CSS 口型图 |
| 口算闯关 | `pages/calc` | **数学第二个玩法**：4 档难度（10 以内加减 / 20 以内进位退位 / 乘法口诀 2~9 / 100 以内，`utils/calc.js` 纯函数出题）→ 大题面 `36 + 28 = ?` + 自绘数字键盘（0~9、退格、✓）；答对语音「你真棒哟」自动下一题，答错语音「答错咯，要加油哟」+ 显示正确答案，可换题/重算；「读题」按钮把算式念出来，「提示」直接给答案；**60 秒限时挑战**（倒计时 + 结算卡：答对/答错/最长连对）；错题本（去重最近 30 道）+「只练错题」；今日对错/连对/正确率统计（`calc.daily/streak`） |
| 竖式计算 | `pages/column` | **数学第三个玩法**：3 档难度（两位数加 / 两位数减 / 三位数加，`utils/column.js` 逐位过程计算）；标准竖式排版（个位对齐 + 等宽横线），**从个位起一位一位填**，填满自动判分；每格上方显示进位/借位小圆标（可开关），当前位的「8 + 5 = 13，写 3 进 1」式分步提示；填错只标红错的那一位；答对/答错语音反馈同口算；错题本 + 统计同构（`column.daily/streak`） |
| 图案与数字连线 | `pages/link` | **数学第四个玩法**：左列「数量点阵」按十格阵摆（每行 5 个点，满行好数），右列打乱的数字；点一个点阵再点对应数字即连上——**真连线**（连线层用旋转线段视图，按两卡中心点实时计算角度长度）；连对变淡打勾 + 「你真棒哟」，连错抖动 + 「答错咯，要加油哟」；3 档（5 以内 / 10 以内 / 20 以内，`utils/link.js` 纯函数出轮，左右列同集合、去重、界内）；全部连对自动进下一轮；看板统计同构（`link.daily/streak`） |
| 思维游戏 | `pages/mind` | **数学第五个玩法，两个小游戏页签**：①走迷宫——递归回溯生成完美迷宫（3 档 5×5 / 7×7 / 9×9，`utils/mind.js`，每次必连通），方向键盘 + 盘面滑动双操作，撞墙震动，走到旗子过关自动换新图；②方块滑块——3×3 数字华容道，从完成态随机走 90 步打乱（**必有解**），点空格旁的块滑动，排好 1~8 过关，记录最少步数；过关语音鼓励，看板统计（`mind` 看板，含 byLevel 最少步数） |
| 单词与跟读 | `pages/words` | **英语第二个玩法**：8 个主题 × 8 词 = 64 词（动物/食物/颜色/数字/家人/学校/身体/动作，`utils/words.js`，含音标/中文/例句/例句中文）；大字词卡**点单词听发音（英文语种）**、慢速开关、点例句读整句；**跟读录音**：最长 6s 自动停 → 回听自己的声音 → 自评「读对啦/再读一次」（不评分只鼓励，读对记入今日进度）；一键收藏进生词本；主题 8 格总览打勾记录；进度/今日已读统计（`words.ids/daily`） |
| 数字测试 | `pages/math` | **数学学科第一个上线玩法**：可设置数字区间（半屏弹层：最小/最大输入 + 6 档预设，0~9999，存 `math.range`）→ 随机出题大数字卡（换题滑入动效、按位数自适应字号、「不会读？」点一下看中文读法提示）；点麦克风**录音与语音识别同步打开**（`utils/asr.js` 封装同声传译插件 `getRecordRecognitionManager`，识别出目标数字 0.6s 后自动收尾判分）；判分用 `utils/numberSpeech.js`：支持阿拉伯数字、中文标准读法（一百零五）、逐位读法（二三/一零五）、口语省略（一百一=110）；读对语音答复**「你真棒哟」**，读错答复**「答错咯，要加油哟」**（固定小女声：女声 + 1.06 倍速，不受家长音色设置影响；TTS 不可用时静默降级为纯文字反馈）；答错自动进错题本（最近 30 个），支持「只练错题」；识别插件不可用时自动降级为「只录音 + 家长确认」，孩子不卡壳；今日答对/答错/连对/正确率统计（`math.daily/streak`），重进保留 |
| 拍照朗读 | `pages/capture` | 拍照/相册多选（≤9 张）、排序整理、OCR 识别进度、逐句校对（改/删/补） |
| 留言板 | `pages/feedback` | **收集用户需求**：礼貌欢迎语 + 三类分类（新功能/优化建议/问题反馈）+ 500 字留言 + 选填联系方式；「大家的留言」列表（分类彩色标签、我的留言标记、今天/昨天/日期时间、**岛主回复蓝色气泡公开显示**）；入口在首页右上「更多」菜单「欢迎留言」；**家长中心「留言管理」为管理员入口**（待回复橙色角标，进入后可回复/修改回复/删除，需管理口令——云函数 `ADMIN_KEY` 常量，发布前务必修改）；数据存微信云开发数据库 `feedback` 集合，经云函数 `cloudfunctions/feedback`（add/list/reply/remove，自动建集合）；云开发未开通时显示引导卡不崩，拉取失败回退本地缓存（`utils/feedback.js`） |
| 听读磨耳朵 | `pages/listen` | **先听后读**：逐句 TTS 自动连播/单句循环、已听进度打勾、音色/语速/拼音开关，听熟后点「我听熟啦，我来读」进入朗读（也可直接跳过） |
| 逐句朗读器 | `pages/reader` | 逐字点读、TTS 范读（可调语速）、真实录音（本机回听）、自动断点、生词收集；顶部「再听一遍」随时回听读页，「重读」一键重置本句 |
| 完成激励 | `pages/reward` | 星星庆祝、编号奖状、真实朗读小结（句数/用时/生词数）；**Canvas 生成海报保存相册**（失败自动降级复制文字）；**海报底部小程序码（推广）**：经云函数 `cloudfunctions/qrcode`（wxacode.getUnlimited，fileID 缓存云存储 `stats_meta`）生成并下载到本地缓存（`utils/qrcode.js`），扫码直达小程序；云端不可用时自动退化为「微信搜索」文案块，保存动作永远成功 |
| 生词本 | `pages/vocab` | **拍照收词**（拍照/相册 → OCR → 自动挑词 → 勾选收入小词库，可手补）、搜索/筛选/发音/掌握标记/删除、复习模式（认识/不熟，复习完可再过一遍）、掌握率统计 |
| 成长档案 | `pages/archive` | 连续打卡、总学情、能力雷达（含明细弹层）、勋章墙（含全部勋章弹层）、家长门禁、更多菜单；用户卡头像显示孩子真实照片（无照片回落 🧒），昵称/照片与家长中心实时同步（`utils/bus.js` 事件总线） |
| 家长中心 | `pages/parent` | 算术门禁、近 7 天周报（柱状图）、**每日完成情况按「月/日」展示（最新日期排第一行，今天高亮；周报柱状图仍按时间从左到右）**、书单进度、年龄模式/拼音/语速/音色/时长/每日目标设置、**手机号绑定（微信号一键获取 + 手填其他号码 + 解绑，绑定后同步云端统计供数据后台展示）**、**留言管理**（仅管理员可见，待回复角标）、**数据后台入口**（仅管理员可见；首次使用显示「认领后只有你的微信能看」）、**导出学习报告（Canvas 生成图片 → 弹窗预览 → 分享给微信好友/保存相册，长按图片也可转发；画布异常退回复制文字版）**、**安全重置**（三档清理：只清学习记录 / 学习记录+孩子资料 / 恢复出厂，两步式：选程度 → 「将删除/将保留」清单确认 → 长按 3 秒执行防误触；清理前自动备份，7 天内家长中心「恢复数据」一键找回；**清完是真空白**（不回带演示书单/生词/演示统计，演示数据仅首次安装出现），`utils/store.js` cleanupPreview/cleanupApply + 快照 API）；**小朗读者 ID**（成长档案用户卡展示，首次访问生成 6 位数字编号 `store.readerId()` 时间戳+随机混合、永久稳定，点按复制；「只清学习记录」保留，恢复出厂重新生成）；**孩子资料**：头像可拍照/相册上传（本地持久化 + 旧头像自动清理 + 失效自动回落）、昵称半屏编辑（1~8 字校验、字数计数）；首页点头像/昵称旁铅笔直达（门禁后自动高亮资料卡）；头像同步显示在首页/成长档案/朗读页/奖状页 |
| 数据后台 | `pages/admin` | **仅管理员本人（openid 白名单）**：云函数按微信身份校验——首次使用输入口令「认领」（口令 + 当前微信绑定，认领后仅此微信能看），其他家长直接看到「仅管理员本人可访问」；通过后四格使用概览（**累计使用次数 / 今日使用次数 / 累计用户 / 今日活跃用户**，含较昨日涨跌、今日新增）+ 近 7 日启动柱状图 + 用户表格式列表（昵称 / 模式 / 脱敏手机号 / 累计使用次数 / 最近使用时间，今天活跃绿点）；可刷新；数据源：`app.js` 每次启动经云函数 `cloudfunctions/stats` 静默上报 track（`stats_users` 按 openid 建档 / `stats_days` 按天计数 / `stats_admins` 管理员白名单），家长绑定手机号后同步 bindPhone（完整号只存云端，后台仅显示 138\*\*\*\*8000 脱敏值，解绑同步清除）；入口在家长中心「账号与数据」，非管理员不显示该入口（`utils/stats.js`） |

## 三、上线前必须做的 3 件事

### 1. 替换 appid
`project.config.json` → `appid` 改为你自己的小程序 appid（当前 `wx3701fb2314a6899a`）。
> 后台添加插件、开通服务市场等操作，都必须用**这个 appid 对应的账号**登录公众平台。

### 2. 语音范读（三通道自动降级）

`utils/tts.js` 支持三种通道，`config/index.js` 的 `tts.provider` 控制：

| provider | 通道 | 适用场景 |
|----------|------|---------|
| `auto`（默认） | 插件 → 云函数 → 提示 | 推荐保持默认，有什么用什么 |
| `plugin` | 微信「同声传译」插件 | 企业主体小程序 |
| `cloud` | 云函数 `cloudfunctions/tts`（腾讯云 TTS） | **个人主体 / 插件加不了** |
| `off` | 关闭范读 | 应急 |

**通道 A：同声传译插件（体验最好，企业主体可用）**
1. 公众平台 → **设置 → 第三方设置 → 插件管理 → 添加插件** → 搜「微信同声传译」或直接填 AppID `wx069ba97219f66d99`
2. 搜不到/申请报 -1 → 去微信服务市场 `mp.weixin.qq.com/wxopen` 搜「微信同声传译」→ 添加插件
3. **个人主体小程序无法使用该插件**，直接走通道 B
4. 插件添加成功后：`node tools/switch-tts-plugin.js on`（版本号不对可 `on <版本号>`），清缓存重编译

**通道 B：云函数 TTS（免费额度 200 万字/月，个人主体推荐）**
1. 开通云开发（开发者工具 → 云开发），环境 ID 填入 `config/index.js` → `tts.cloudEnv`
2. 开发者工具中 `cloudfunctions/tts` 右键「上传并部署：云端安装依赖」
3. 云开发控制台 → 云函数 `tts` → 配置 → 环境变量：`TENCENT_SECRET_ID` / `TENCENT_SECRET_KEY`（腾讯云访问管理 CAM 的密钥，只存服务端；可选 `TTS_MODEL_TYPE`：0 女声 / 1 男声）
4. 完成。`auto` 模式下插件不可用会自动走云函数；启动时 Console 会打印 `[书声岛] 范读语音已就绪（云函数 TTS）`

**手机号绑定云函数（`cloudfunctions/phone`，可选）**

1. 需求：家长中心「去绑定」用微信手机号一键获取。**仅已认证的非个人主体**可调用；个人主体点「去绑定」会提示原因并引导手填其他号码
2. 部署：`cloudfunctions/phone` 右键「上传并部署：云端安装依赖」（无第三方依赖）
3. `config/index.js` → `account.cloudEnv` 填云开发环境 ID（与 ocr/tts 相同即可）

**音色切换（仅云函数通道支持）**

- 听读页顶部有「女声 / 男声」胶囊 → 点开半屏面板，**点一下就用当前这句试听**，选中即保存为默认
- 家长中心「伴读设置 → 范读音色」可改默认值；两处共用同一个 `user.ttsVoice` 存储
- 插件通道音色固定不可切换，此时两处入口会自动置灰并提示原因
- 前端传参：`tts.speak(text, { voice: "female" | "male" })` → 云函数 `event.voice`（0 女声 / 1 男声）→ `ModelType`；未传时回落到环境变量 `TTS_MODEL_TYPE`
- 缓存按「语速 + 音色 + 文本」区分，同一句不同音色分别缓存

**描写页读音**

- 练习卡左上有「读音」胶囊（播放时变实心蓝并闪动），读当前字；组词胶囊点一下读该词
- 语音通道与范读共用（插件/云函数），走用户设置的语速与音色；切换生字时自动停掉上一条读音

**拍照收词（生词本 → 小词库）**

- 生词本顶部天蓝相机按钮或「拍照收词」入口卡 → 拍照/相册选一张 → OCR 识别 → 自动挑出候选词
- 挑词算法：按标点断句 → 2/3 字滑窗 → 过滤虚词起止 → 句首/句尾/虚词邻接加分；**默认只勾选有边界线索的高分词**，全部候选以 chips 展示可增减
- 支持弹层内手动补词、查看识别原文；OCR 未配置时走演示识别并有黄色提示条
- 收入的词带原句上下文，与朗读时收集的生词共用同一份 `store.vocab`

## 四、关键设计约定（与 PRD 对应）

- **先听后读**：识别完成后先进「听读磨耳朵」页（`pages/listen`），逐句自动播放；是否开口、何时开口由孩子自己决定（「我听熟啦，我来读」随时可点）。已听状态记在句子的 `heard` 字段，不计入朗读统计与勋章
- **v1 不做语音评测**：读完一句给鼓励星，星级来自完成度，不是发音打分
- **录音不上传**：`wx.getRecorderManager` 本机录音，仅用于回听
- **账号**：微信静默登录 + 本地存储（`wx.setStorageSync`，key `wj_store_v1`）；手机号绑定优先走微信「获取手机号」（`<button open-type="getPhoneNumber">` → `code` → 云函数 `phone` 调 `phonenumber.getPhoneNumber` 换真号，仅「已认证的非个人主体」可用），拿不到时自动降级为手填其他号码（正则校验、显示脱敏、可解绑）；**绑定后手机号同步到云端统计**（`cloudfunctions/stats`，完整号仅存云端、数据后台只显示脱敏值、解绑同步清除；需在小程序后台《用户隐私保护指引》声明收集手机号）
- **使用统计**：每次启动经云函数 `stats` 静默上报（openid 建档 + 按天计数），失败不影响使用；管理后台查看需口令（`ADMIN_KEY`，feedback/stats 两处一致，发布前必改）
- **幼儿园模式**：无星级对比文案、鼓励语不同，设置里一键切换
- **打卡口径**：自然日内朗读 ≥1 句即打卡；勋章全部由 `store.overview()` 实时计算，新增勋章只改 `BADGE_DEFS`
- **拼音**：离线词典覆盖小学高频字，多音字取常用音；未命中的字不显示拼音（显示空位），可后续替换为在线注音
- **学科分区**：首页按 语文/数学/英语 切换（`user.subject` 持久化）；v1 只有语文是完整功能，数学（口算闯关）与英语（单词跟读）展示筹备中规划卡，避免假入口；打卡与勋章目前跨学科共用
- **描写字库**：`utils/chars.js` 按学段组织（每字自带拼音+组词，不依赖在线数据）；写字进度记在 `store.writing`（按字计次 + 按日计数），写字数不影响朗读勋章，后续可加「小小书法家」勋章
- **横屏笔顺**：`utils/strokeData.js` 由 `tools/gen-strokes.js` 从 hanzi-writer-data（MIT）离线生成（124 字共 40KB，每笔存中心线折线，坐标归一化 0~1000）；`utils/strokePlay.js` 负责三态绘制（已写/正在写/未写）与笔尖；横屏布局全部用 px 计算（rpx 随屏宽膨胀），旋转时先把笔迹转归一化坐标、重建画布后按新尺寸还原；深链 `?char=请` 不带学段时会全字库查找

## 六、常见报错对照

| 现象 | 原因 | 处理 |
|------|------|------|
| 控制台 `插件 wx069ba97219f66d99 ...`，页面白屏/编译失败 | 后台未添加「同声传译」插件 | 公众平台 → 设置 → 第三方设置 → 插件管理 → 添加插件；完成后清缓存 + 重新编译 |
| `plugin "WechatSI" is not declared in app.json` | 执行过 `switch-tts-plugin.js off` | `node tools/switch-tts-plugin.js on` |
| `插件版本不存在` / `invalid plugin version` | `app.json` 的 `version` 与后台不一致 | 看后台插件详情里的版本号，`node tools/switch-tts-plugin.js on <版本号>` |
| 编译通过但点范读提示「范读语音未开启」 | 插件未加载成功（未授权 / provider 设为 off） | 页面 Console 执行 `requirePlugin('WechatSI')`，报错即回到第一条 |
| 真机播放无声 | 手机媒体音量为 0 | `tts.js` 已设 `obeyMuteSwitch = false`，只需检查媒体音量 |
| 合成失败（`SYNTH_FAIL`） | 文本含 emoji/特殊符号，或超长 | 插件限 200 字、云函数限 45 字（`cloudMaxChars`），超出自动截断 |
| 服务市场添加插件报 `申请插件失败 -1` | 小程序未设置服务类目 / 基本信息不全 / **个人主体** / 账号违规受限 | 先补类目和基本信息重试；个人主体或账号被处罚（如「无法被搜索」）则走通道 B |
